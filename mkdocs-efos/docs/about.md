# About

## Executive Function OS

Executive Function OS began as a conceptual system (Battle Map) to describe internal terrain: strain, fragmentation, and survival. 
It has since evolved into a computational platform that models cognitive network fragmentation using percolation theory.

> “Sometimes you have to describe the terrain before you can model it. Sometimes the first useful system is the one that helps you recognize your own patterning clearly enough to build something real.”

## Research Objectives

- Provide a transparent, reproducible tool for computational psychiatry
- Bridge the gap between subjective experience and quantifiable network metrics
- Offer neurodivergent professionals and researchers a privacy-first way to analyze executive function dynamics

## Privacy & Ethics

- Client-side architecture — no server access to your data
- Research ethics informed consent in place
- Not a medical device; requires professional interpretation
