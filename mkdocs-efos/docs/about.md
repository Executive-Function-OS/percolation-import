# About

## Executive Function OS (EFOS)

Executive Function OS (EFOS) is a privacy-preserving digital phenotyping infrastructure that models cognitive network fragmentation using percolation theory and DBSCAN clustering. It converts naturalistic behavioral trace data into quantitative structural phenotypes of executive function entirely client-side.

## Research Objectives

- Provide a transparent, reproducible tool for computational psychiatry and life-sciences research.
- Offer researchers a privacy-first, client-side approach to extract structured phenotyping metrics for downstream analysis pipelines without exposing raw trace data.
- Validate percolation-based network models against convergent cognitive and clinical measures of executive function.

## Privacy & Ethics

- **Fully Local Computation:** All processing is done client-side in the user's browser; no raw behavioral data leaves the device.
- **Ethics & Consent:** Built to align with institutional review board (IRB) protocols for longitudinal research.
- **Diagnostic Disclaimer:** EFOS is a research tool, not a clinical diagnostic.

## Current Status & Traction

- **Validation:** Internal/N=1 proof-of-concept validated on simulated and limited real data.
- **External Pilot:** Pilot cohort currently recruiting via the [Participate](participate.md) page.
- **Open Codebase:** GitHub metrics and repository activity are available for audit now that the codebase is public.
