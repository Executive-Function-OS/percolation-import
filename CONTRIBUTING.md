# Contributing (research collaborators)

1. **Fork & branch** — open a PR against `main` with a short methods note if you change analysis code.
2. **Client-side rule** — do not add server endpoints that receive raw Drive payloads unless IRB and security review are documented.
3. **Tests** — run `npm run test` before pushing; add Vitest cases for new metric or classification logic.
4. **Attribution** — credit methodological suggestions in code comments or README when adding algorithms tied to external collaborators.

See `DATA_SHARING.md` for anonymization expectations.
