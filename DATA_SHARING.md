# DATA SHARING PROTOCOL

## Anonymization Protocols
- All personally identifiable information (PII) will be removed from the dataset before sharing.
- Data will be aggregated to prevent the identification of individuals.
- Any data shared will be zipped and password-protected.

## User Rights
- Users of the dataset must agree to use it solely for research purposes.
- Users must acknowledge the source of the data in any publications resulting from its use.
- Users must report any security breaches immediately.

## Research Ethics Compliance
- All data sharing must comply with institutional review board (IRB) protocols.
- Consent forms must outline how data will be used and shared.
- Users must adhere to the principles of respect, integrity, and transparency in research.
